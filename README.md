## 📌 주요 구현

### 맵 렌더링 최적화

- 대형 맵을 통째로 렌더링할 때 카메라 밖 지형까지 처리되는 부담을 줄이기 위해 옥트리 기반 공간 분할과 프러스텀 컬링 구현.
- 각 삼각형의 세 정점이 속한 Octant를 비교해 모두 같은 구역이면 해당 자식에 배분. 서로 다른 구역에 걸치면 부모 노드에 보관해 경계 삼각형의 중복 저장과 컬링 누락 방지.
- 노드 전체를 그릴 메쉬와 부모에 남은 경계 삼각형만 그릴 메쉬를 구분. 노드 전체가 판정을 통과하면 하위 탐색 없이 전체 메쉬를 렌더링하고, 일부만 통과하면 경계 면을 처리한 뒤 자식을 재검사.
- 화면 밖으로 판정된 노드는 하위 탐색과 렌더링에서 제외. 카메라 이동에 따라 필요한 구역을 단계적으로 선별하면서 분할 경계의 지형도 함께 표시.
- 메쉬당 평균 인덱스 수와 노드 크기를 기준으로 분할 종료 조건 설정. 작은 구역까지 계속 분할되는 것을 제한하고, 노드 전체 렌더링과 하위 탐색을 선택할 수 있도록 구성.

### 사자 보스 전투 시스템

- 연속 공격마다 다른 타격 시점과 판정 부위를 애니메이션에 맞추기 위해, 애니메이션별로 발동 진행률과 히트박스 종류를 등록하는 타이밍 정보 구성.
- 현재 애니메이션에 등록된 항목을 순회하며 재생 진행률이 발동 기준에 도달했는지 검사. 아직 실행하지 않은 항목의 히트박스를 활성화해 동작과 실제 타격 시점 연결.
- 실행한 항목은 플래그를 기록해 같은 재생 중 반복 발동 방지. 해당 애니메이션을 다시 시작할 때 플래그를 초기화해 동일한 타이밍 정보 재사용.
- 한 번의 검사에서 미실행 항목 하나를 처리한 뒤 반환하는 방식 적용. 공격별 타격 시점과 판정 종류를 등록 정보로 관리해 연속 공격의 여러 타격 구간 구성.

### 사자 보스 애니메이션 및 연출

- 보스가 공격 중 피격되어도 기본 공격 동작은 유지하고 얼굴과 입 등 일부 부위에만 반응을 표현하도록 부분 애니메이션 구현.
- 부분 애니메이션에 사용할 Bone 인덱스를 유효 집합으로 관리. 채널을 순회하며 해당 Bone이 집합에 포함된 경우에만 부분 애니메이션의 키프레임으로 추가 갱신.
- 기본 동작을 갱신한 뒤 선택한 부위의 변환을 덮어쓰고, 해당 Bone의 결합 행렬을 다시 계산해 최종 자세에 반영.
- 전신 애니메이션을 피격 동작으로 교체하지 않고 공격과 부위별 피격 반응을 함께 표현하도록 구성.

### 오브젝트 풀링

- 보스의 연속 공격에서 다수의 바위와 파편이 반복 등장하므로, 전투 중 생성과 제거를 줄이기 위해 바위와 파편을 각각 400개 사전 생성.
- 공격 패턴에서 사용할 풀 인덱스를 선택하고 위치, 크기, 회전, 숨김 상태와 타이머를 초기화해 이전 사용 상태가 남지 않도록 처리.
- 사용 중인 객체의 인덱스를 활성 목록에 등록하고, 매 프레임 활성 목록만 순회해 풀 전체를 갱신하는 부담 축소.
- 수명이 끝나 숨김 상태가 된 객체는 활성 목록에서 제외하되 객체 자체는 보관. 다음 공격에서 상태를 다시 설정해 재사용.
- 패턴별 인덱스로 객체를 선택하는 방식으로 다량의 바위와 파편 연출을 구성하고, 객체 재사용과 현재 갱신 대상 관리를 분리.
