# 커비 디스커버리 모작

**Kirby and the Forgotten Land** 모작 팀 프로젝트입니다.

▶️ [플레이 영상 보기](https://youtu.be/M6XyYSIXpAo)

📅 **개발 기간** : 2024.06 ~ 2024.07 (8주)  
👥 **개발 인원** : 6인

## 🛠️ 사용 기술

- C++
- DirectX 11
- HLSL
- PhysX
- ImGui / ImGuizmo

## 📌 담당 업무

### 맵 렌더링 최적화

- 대형 맵 메쉬를 Octree 노드 단위로 재귀 분할하고 삼각형을 공간별로 분류
- 절두체 포함 여부에 따라 노드 전체 또는 부분 메쉬만 렌더링하는 Frustum Culling 구현

### 맵 제작 도구

- `ImGui`, `ImGuizmo` 기반 맵 툴을 통해 오브젝트·지형 배치 및 Transform 편집 기능 구현
- 맵 데이터 저장·불러오기 기능을 구현해 팀 전체의 레벨 제작에 활용

### 사자 보스 전투 시스템

- 상태 기반 애니메이션 전환과 공격 패턴 로직 구현
- 애니메이션 진행률에 맞춘 히트박스 활성화와 외적을 활용한 플레이어 좌우 위치 판별

### 사자 보스 애니메이션 및 연출

- 눈동자 UV 오프셋을 조절해 플레이어를 추적하는 시선 처리 구현
- 피격 시 특정 Bone을 독립 갱신하고 Layered Animation을 적용한 부분 애니메이션 구현

### 오브젝트 풀링

- 보스 전투에 사용하는 바위와 돌 파편을 미리 생성하고 재사용하는 오브젝트 풀링 구현
- 패턴별 위치, 방향, 크기 및 낙하 속도를 조절해 다량의 파편 연출 생성 비용 절감
