✨✨✨게임 언팩 및 플레이✨✨✨
[Ryujinx]
https://github.com/Ryujinx/Ryujinx
- 닌텐도 스위치 게임 에뮬레이터
- 에뮬레이터로 게임 실행하여 플레이 가능


0. 다운로드/압축 해제 후 exe 실행
- 에러 팝업 출력될 경우, 무시하고 대기 상태 유지

1. Prod-Key & 펌웨어 최신 정보 다운로드
- 다운로드 후 압축파일 해제. 동일 버전이어야 에러 발생하지 않음

[Prod-Key] https://prodkeys.net/ryujinx-prod-keys-download/#more-18
[펌웨어] https://prodkeys.net/switch-firmwares-download/#more-106

	1) File > Open Ryujinx 선택하여 파일 탐색기 오픈
	2) System 폴더에 사전 다운로드한 Prod-Key 폴더의 prod/title.keys 삽입
	3) Tools > Install Firmware > Install a firmware from XCI or ZIP 선택하여 펌웨어 .xci/.zip 선택하여 적용

2. 실행할 게임 경로 지정
	1) Options > Settings 선택하여 팝업 오픈
	2) General / Game Directories 의 [Add] 버튼 선택
	3) .nsp 파일이 존재하는 경로 지정


3. 정상적으로 게임 인식될 경우, 목록에 출력되며 더블클릭하여 실행 시 실행기 윈도우 출력

4. 리소스/데이터 추출
	1) 추출이 필요한 경우, 실행중인 윈도우 종료 후 목록에서 추출할 게임 우클릭
	2) Extract Data > RomFS 선택하여 경로 설정 후 추출 진행




✨✨✨리소스 프리뷰어✨✨✨
[Switch-Toolbox]
https://github.com/KillzXGaming/Switch-Toolbox
- 스위치 게임 리소스/데이터 미리보기


0. 다운로드/압축 해제 후 exe 실행
1. File > Open/Open(Folder) 선택하여 확인할 데이터 경로를 지정 (아래 참고)
2. 좌측 지정한 경로 미리보기 출력
3. 모델/애니메이션/텍스처 등의 추출이 필요할 경우, 해당 파일 선택 후 우클릭 > Export
	ex1) 모델
		(1) File > Open(Folder) > 모델 정보 파일 Model.bfres.cmp 선택
		(2) Models > TopL 선택 후 우클릭 > Export > .dae 확장자 파일로 추출
			(이 경우는 추출 직전 팝업에서 텍스처와 같이 추출할 건지 여부를 물어봄)

	ex2) 애니메이션 
		(1) File > Open > 애니메이션 정보 파일 Motions.bfres.cmp 선택
		(2) Animations > Skeletal Animations 내 임의 애님 선택 후 우클릭 > Export > .seanim 확장자 파일로 추출
			- 애니메이션 파일만 선택 후 추출 시도할 경우 에러 발생. 반드시 사전에 모델 선택 후 추출하기


4. 애니메이션 미리보기
	1) 모델 경로가 존재하는 탭 선택 후, 모델 파일 선택
	2) 애니메이션 경로가 존재하는 탭 선택 후, 애니메이션 선택
		- 상단 3D 버튼 선택하여 활성화
		- 선택 애니메이션 하단 TimeLine의 재생 버튼 선택
	3) 모델 탭 선택하여 돌아가서 움직이는 모델 확인 가능

✨✨✨블렌더 플러그인(애드온)✨✨✨
[io_anim_seanim]
https://github.com/SE2Dev/io_anim_seanim
- 블렌더 플러그인 이식하여 애니메이션 가져오기 가능

0. 블렌더 설치 및 한국어 옵션 설정
1) 상단의 필수 애드온 설치
2) (모델) 파일 > 가져오기 > Collada (.dae) 선택 후, 추출한 .dae 모델 파일 로드
3) (애니메이션) 우측 뷰 레이어에서 모델의 Armature 선택 
	- 파일 > 가져오기 > SEAnim (.seanim) 선택 후, 추출한 .seanim 애니메이션 파일 로드
